# P2 checkpoint (partial): classical baseline and training script

Date: 2026-11-06. Fine-tuning is deferred to the team's training PC (user decision).

## Done and verified
* `src/vision/features.py`: frozen 1816-dim handcrafted vector (HOG 1764, uniform LBP 10,
  HSV 16/8/8, geometry 8 measured before square resizing, flags 2). Blank, tiny and extreme
  crops give finite values plus quality flags. Config: `configs/features.yaml` (`hc_v1`).
* `src/vision/proposals.py`: fully classical ROI proposal baseline (Canny, morphology,
  contours, bounded area/edge-support score) with a defined empty failure.
* Versioned caches (`scripts/cache_features.py`, `src/models/cache_io.py`): keyed by manifest
  hash, crop policy, feature version and config hash; loading refuses mismatches. Train
  (6,514) and tune (815) classical caches built in 48 s on 7 CPU workers.
* Classical head (`scripts/fit_heads.py --head classical`): StandardScaler + multinomial
  logistic regression, grid C in {0.005, 0.02, 0.1} fixed in `configs/heads.yaml`.

  | C | Tune top-1 | Tune top-5 | Tune NLL | Train top-1 |
  |---|---|---|---|---|
  | 0.005 (selected) | 0.1865 | 0.3816 | 3.966 | 0.965 |
  | 0.02 | 0.1779 | 0.3914 | | |
  | 0.1 | 0.1755 | 0.3791 | 4.198 | 0.999 |

  Population: tune partition (815 images), annotation crops with 5% margin. This is an
  oracle-crop development diagnostic, not test or end-to-end accuracy. The selected value is at
  the edge of the fixed grid; the grid was not widened. The head overfits strongly (train 96%),
  as expected for 1816 handcrafted features and ~33 images per class.
  Artifact: `D:/semevia_work/store/heads/classical_hc_v1_C0.005.joblib`, SHA256 in
  `reports/classical_tune.json`.
* `scripts/train.py` + `src/models/training.py`: two-stage resumable EfficientNet-B0 training
  (head, then `features.7`/`features.8` unfrozen), best/last/best_finetuned checkpoints with
  optimizer, scaler and RNG state, split-hash check on resume, pretrained-weight change check.
  Smoke-tested on CPU with 64 images, 0 and 2 loader workers, including resume. The smoke run
  is labelled and reports `fine_tuning_requirement_met: false`.
* 37/37 tests pass.
